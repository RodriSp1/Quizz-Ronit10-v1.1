# Quiz de preguntas

Aplicación interactiva de cuestionario de opción múltiple con retroalimentación inmediata por respuesta y cálculo de puntuación final.

## Funcionalidades
- Navegación secuencial entre preguntas con indicador de progreso.
- Validación visual de respuestas correctas e incorrectas al seleccionar una opción.
- Pantalla final con resumen de puntaje obtenido y opción para reiniciar el intento.

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript

## Ejecución local
1. Clona o descarga este repositorio.
2. Abre el archivo `index.html` en tu navegador.
